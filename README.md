## Overview

Tale of Two Wastelands is an ambitious total conversion mod that merges Fallout 3 and all its DLC into Fallout New Vegas as a seamlessly accessible world. Players can travel between the Capital Wasteland and the Mojave Wasteland on one character, sharing perks, skills, karma, and inventory — effectively creating a combined mega-RPG using the more stable and modder-friendly New Vegas engine.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Tale of Two Wastelands** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Full FO3 Integration** | Complete Fallout 3 campaign and all DLC integrated into New Vegas |
| **Shared Character** | One character progression shared across both wasteland regions |
| **NV Engine Stability** | Runs on the more stable and mod-friendly New Vegas executable |
| **Cross-World Travel** | Seamless travel between Capital Wasteland and the Mojave |
